# Py Building | Viviendas Modulares Premium

Sitio web corporativo de **Py Building**, empresa paraguaya dedicada al diseño, fabricación y montaje de viviendas modulares y estructuras en sistema Steel Frame.

**Sitio web oficial**: [https://pybuilding.com.py](https://://pybuilding.com.py)

## Funcionalidades

- Diseño adaptable (responsive) para escritorio y dispositivos móviles.
- Catálogo de modelos: V3, V5, E95, V95 y H90.
- Galería por modelo con vista previa de fachada, plano e interior, más visor ampliado (modal).
- Enlaces directos a WhatsApp con mensaje predefinido para cotizar cada modelo.

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid y Media Queries)
- JavaScript (ES6)
- Google Fonts (Montserrat)
